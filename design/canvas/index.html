Swept design canvas

The design target for v0.4 — not the current build. Each artboard is a first-party exemplar the ux-critic subagent scores against, which is what makes “distinctive” checkable without shipping anyone else’s copyrighted screenshots.

Register: native Mac pro-tool — DaisyDisk / Raycast / Linear. Depth from hairlines and vibrancy, not gradients. Numbers are the hero. Restraint over flourish, and the safety story visible at every step.

Artboard 01

Foundations

Seven flat tokens become a measured system. The contrast figures below are computed WCAG 2.1 ratios, not estimates — the worst text pair is 4.77:1 and the worst graphic pair is 3.70:1, so every combination clears AA before a single screen is drawn. The accent is split into three roles that must never be swapped: this is the trap that makes most dark UIs fail a11y, because the vivid system blue is only 3.65:1 against white and cannot legally carry a white label.

Artboard 02

Shell — window chrome and module sidebar

The two-tab pill row becomes a persistent vibrancy sidebar with the traffic lights inset over it (titleBarStyle: "Overlay" + hiddenTitle). Every module carries a live size badge, so the sidebar doubles as the answer to “where is my disk going?” before you open anything. Modules that can only ever read are grouped apart from those that can dispose — the discovery/disposal split from the architecture, made visible.

Artboard 05

Smart Scan — results

The number is the hero, at 52px tabular, with the ring showing the same total broken into its categories — one shape carrying both the sum and the composition. Below it the four independent flat bars of v0.2 become a single proportional stack, which is what actually answers “what is taking the space?”. Small categories get a 3px minimum width, so Logs at 0.08% of the total reads as small rather than as zero. “Preview only” sits next to the number, not in a footnote.

Artboard 06

First, the recoverability promise is the largest text after the count. Artboard 07

Module screen — Large & Old Files

This is where the architecture becomes visible. These files live outside the cleanup allowlist — the app can see them but has no standing permission to remove them, so nothing is pre-selected and each row is an individual grant. The amber banner is not decoration; it is the UI of Consent.granted. Note the footer counts only what you picked, and the primary button stays disabled at zero.

Artboard 08

Space Lens

Purely read-only — this module never touches the executor, and the absence of any checkbox on screen is how the user knows. Rings are depth, hue is inherited from the top-level folder so a child is always visibly part of its parent, and the centre reports whatever the cursor is over. This is the one place where Swept earns a comparison to DaisyDisk, so it gets the most visual weight of any module.

Artboard 09

Onboarding — Full Disk Access

TCC gates ~/.Trash and ~/Library/Containers, so without this permission a scan silently under-reports. The screen says what it needs, what it will still do if you decline, and opens the exact System Settings pane rather than describing where to click. Skipping is a real option, not a dark-pattern dead end.

Let Swept see the whole picture
macOS keeps a few folders private until you say otherwise. Without access, a scan still works — it just cannot see what is in them, and will quietly report less than is really there.
The Trash on every volume
Usually the single largest reclaimable category
 ~/.Trash
Sandboxed app caches
Mail, Messages, and App Store apps
 ~/Library/Containers
Access lets Swept read those folders. It changes nothing about what may be removed — the protected list, the allowlist, and your confirmation all still apply.

Artboard 10
